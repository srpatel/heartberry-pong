## Title Screen

- circles representing controllers moving around
- press A to be ready / B to cancel
- left stick to move around
- Y to change face and/or colour
- zones on left/right for each team
- if there is at least one ready circle in each zone, and all circles in each zone are ready, a game countdown begins
- countdown cancelled if any of the conditions stop being met

## Game Screen

- paddles on left and right, in player colours, with player faces
- length of paddle larger with fewer players
- press A to switch between paddle and face
  when face, paddle remains in place and ghostly
- when face you can move around freely (can no longer block ball)
- stars spawn around, when you get 3 stars, you level-up and pick an upgrade
  for now, each star is 1 point
- first to 5 points wins
- press start to pause game and bring up pause modal

## Pick level-up screen

- modal, game paused
- face at top of modal
- pick one of three options

## Game over screen

- game slows down
- modal appears: winners/losers
